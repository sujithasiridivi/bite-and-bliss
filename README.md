# Bite & Bliss

A recipe website built with HTML5, CSS3 and JavaScript, with no frameworks, backend or database. Visitors can browse 65 dishes across 10 cuisines, open full recipes, save favourites and add their own recipes. All data is stored in the browser using Local Storage.

## Features
- 65 dishes across 10 cuisines
- User registration and login
- Individual recipe pages
- Add your own recipes
- Favourites page for saved dishes
- User profile page and admin page
- Responsive layout with an elegant champagne, antique gold and burgundy colour palette

## Pages
| Page | Purpose |
|---|---|
| `index.html` | Home page |
| `register.html` / `login.html` | Create an account and sign in |
| `recipes.html` | Browse all recipes |
| `recipe.html` | View a single recipe |
| `add-recipe.html` | Add a new recipe |
| `favorites.html` | View saved favourites |
| `user.html` | User profile |
| `admin.html` | Admin page |

## Technologies
HTML5, CSS3, JavaScript, Local Storage

Fonts: Playfair Display, Cormorant Garamond and Jost. Images from Unsplash.
